# KHL Reels

ИИ-аватар, который каждый день после матчей автоматически публикует Instagram Reels про турнирную таблицу КХЛ (Континентальная хоккейная лига).

## Пользователь
- Общается на русском, отвечать по-русски, просто и по шагам.
- Часто диктует голосом, поэтому в тексте бывают оговорки. Понимать по смыслу.
- Windows 11, PowerShell. Опыт программирования пока неизвестен, уточнить.

## Конвейер
1. **Данные**: свежая таблица и результаты матчей (khl.ru или другой источник).
2. **Сценарий**: короткий текст на 20–40 с через Claude API (кто поднялся, кто упал, сенсация дня).
3. **Голос**: озвучка (ElevenLabs или аналог).
4. **Аватар**: говорящий ведущий (HeyGen / D-ID / Synthesia).
5. **Монтаж**: вертикальное видео 9:16, аватар плюс анимированная таблица. Делаем на **Remotion**.
6. **Публикация**: Instagram Graph API или сервис-посредник (Posty / Ayrshare).
7. **Расписание**: ежедневный запуск (сервер или GitHub Actions).

## План MVP (идём маленькими проверяемыми шагами)
- [ ] Шаг 1: забрать таблицу КХЛ → сделать вертикальную картинку или видео (Remotion)
- [ ] Шаг 2: сценарий и озвучка
- [ ] Шаг 3: подключить аватар
- [ ] Шаг 4: автопубликация и расписание

## Ограничения
- Для Instagram Graph API нужен Business- или Creator-аккаунт, привязанный к странице Facebook, и приложение в Meta for Developers.
- Логотипы КХЛ и клубов охраняются: используем названия, цвета клубов и свой дизайн.
- Instagram заблокирован в РФ, поэтому сервер для публикации лучше держать за рубежом.

## Окружение
